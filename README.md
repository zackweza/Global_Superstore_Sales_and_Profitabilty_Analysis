# Global Superstore Sales and Profitability Analysis

## 1. Project Overview

This project analyzes the Global Superstore dataset using Python and Pandas to assess data quality, prepare the data for analysis, and investigate business performance, with a particular focus on profitability.

The goal is to identify data quality issues, understand sales and profit patterns, and develop evidence-based business insights.

## 2. Business Problem

Businesses need reliable sales data to understand their performance and identify factors that influence profitability. Incomplete or inconsistent data can affect the accuracy of business decisions.

This project follows a structured analytical workflow to assess data reliability and explore profitability-related business questions.

## 3. Tools and Technologies

- Python
- Pandas
- Jupyter Notebook
- Excel dataset (`.xlsx`)

## 4. Project Workflow

The project follows these stages:

1. Dataset loading and structural inspection
2. Missing-value assessment
3. Duplicate-record assessment
4. Data type assessment
5. Invalid and suspicious value assessment
6. Categorical consistency assessment
7. Numerical and date quality assessment
8. Documentation of data quality findings
9. Exploratory analysis of sales and profitability
10. Interpretation of business findings
